# MotorScape

A static front-end for a fictional car sales site, built with plain HTML, CSS and JavaScript. The interface is in Romanian.

## What it does

- **Listings page** with ten cars, each linking to its own detail page with a photo gallery.
- **Search, filter and sort** on the listings page: by name, brand and price range, sorted by price ascending or descending. This runs in the browser, with no back end.
- **Home, About and Contact pages**, each with its own stylesheet.

## Running it

No build step or server is needed. Open `MotorScape/acasa.html` (home) or `MotorScape/index.html` (listings) in a browser.

## Structure

```text
MotorScape/
  acasa.html, index.html, despre.html, contact.html
  masini/    one detail page per car
  css/       stylesheets
  js/        filtering, sorting and gallery scripts
  images/    photos used on the pages
```

## Notes

The cars, prices and seller details are made up for the exercise. The photos are used for demonstration only and belong to their original owners.
